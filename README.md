📂 Featured Project
🎬 Cosmos Cinema Management System
- Repository: CINEMA-MANAGEMNET-SYSTEM
- Tech: C#, ASP.NET Core MVC, .NET 8, Razor Views, HTML, CSS, JavaScript, Entity Framework Core, SQL Server.
- Description: A cinema management and online ticket booking system covering movie browsing, showtime selection, seat selection, food and drink combos, payment, and booking history.
- Key Features:
  - 👤 Registration, login, and role-based access for customers, staff, and administrators.
  - 🎞️ Movie information and daily screening schedules.
  - 💺 Showtime selection, seat types, and booked-seat availability checks.
  - 🍿 Food and drink combo selection.
  - 💳 QR payments through SePay/VietQR with webhook transaction confirmation.
  - 🎟️ Booking history, movie ratings, and reviews.
  - 🤖 Movie recommendations using ML.NET and a chatbot for movie discovery.
  - 🛠️ Management of movies, screenings, cinema rooms, combos, and staff accounts.
- Highlights: Combines booking workflows, authentication, payments, and movie recommendations in a web application built with MVC architecture.
- Learning Value: Practical experience with relational databases, Entity Framework Core/LINQ, user authorization, and external service integration.
